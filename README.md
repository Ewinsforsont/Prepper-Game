# Prepper Game

A VR experience developed at **Blekinge Institute of Technology (BTH)** for the course *Utställningsteknik* (Exhibition Technology) in 2025.

## Overview

Prepper Game is an exhibit-style, hands-on VR application for **Meta Quest** that teaches users about Swedish emergency preparedness (*hemkrisförråd / beredskap*). Players physically pick up and sort household items into a storage area, learning what belongs in a home crisis kit and why.

## How It Works

Using hand-tracking (**Oculus Interaction SDK**), visitors grab real-world emergency items — water containers, food, heat and lighting supplies, hygiene products, clothing, communication devices, and comfort items — and place them into a designated storage zone. Each object is tagged to one of five resource categories:

- 💧 Water
- 🍞 Food
- 🔥 Heat
- 🚽 Sanitation
- 📦 Miscellaneous

Correct placements contribute to a score across these categories, giving users immediate feedback on how well-prepared their virtual household is.

## Purpose

The project aims to raise awareness of crisis preparedness in an engaging, embodied way — demonstrating through interaction rather than instruction what it means to be ready if essential resources become scarce.

## Built With

- **Unity 2022.3 LTS**
- **Meta XR SDK** / **Unity XR Oculus**
- **Oculus Interaction SDK** (hand grab interactions)
- **FMOD** — spatial and zone-triggered audio
